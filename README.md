# Macbeth Act 1: teaching site (Lessons 1 and 2)

A single-page teaching tool for Year 8. It works as the main display in class (smartboard) and as a revision tool at home (the Revise tab).

## Publish it with GitHub Pages
1. Create a new repository on GitHub (for example `macbeth-act1`).
2. Upload `index.html` to the repository.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Keep these OUT of the public repository
GitHub Pages sites are public, and students can view a page's source. Do not upload:
- the assessment paper and mark scheme,
- the answer key,
- lesson plans and the teacher guide.

Store those on Moodle or a private drive. Everything inside `index.html` (gap-fill answers, exit ticket answers, quiz answers) is meant for students to see, because it supports revision.

## Using it in class
- Arrow keys move between steps. `[` and `]` move between notes. `Esc` closes a note.
- Buttons at the top: Timer, text size (A− and A+), Night mode, Full screen.
- Each lesson runs: Aims and do-now, then extracts with tap-to-open notes, gap-fills, quick checks, and an exit ticket.
- Notes marked with a starter or stretch prompt show "Need a starter?" and "Push further".

## Using it at home
Students open the same link and choose **Revise**: key quotes, a quick quiz, gap-fills and a self-rating page.

## Privacy
The site collects no data and sends nothing anywhere. The self-ratings on "Am I ready?" are saved only in that browser on that device.

## Text and fonts
Extracts are from the Folger Shakespeare Library online edition (folger.edu), with line numbers as printed there. Check their terms if you plan to share the site widely.
Fonts (Literata and Atkinson Hyperlegible) load from Google Fonts. Without internet the site falls back to system fonts.
